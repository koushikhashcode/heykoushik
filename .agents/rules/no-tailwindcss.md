# Rule: No TailwindCSS

## CSS & Styling Guidelines
- **NEVER use TailwindCSS** in this project (`portfolio`).
- Do NOT install `@tailwindcss/vite`, `@tailwindcss/postcss`, or any Tailwind CSS packages.
- Do NOT add `@import "tailwindcss";` or `@tailwind` directives in any `.css` or `.scss` file.
- All styles MUST be written in **Vanilla CSS** (or standard modular CSS) to preserve exact design tokens, typography, and font sizing without global preflight style resets.
